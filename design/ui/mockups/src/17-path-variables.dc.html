17 · Path Variables

A :name segment in the URL is drawn as a token, and the Params pane grows a "Path Variables" table under "Query Params" while the URL has one. The URL is the source of truth for which names exist: Name is read-only, only Value is typed. The table has no checkbox, no delete and no trailing row, and goes away when the last :name leaves the URL. The Params count stays on Query Params. Below: editing a value, an Undefined Variable in a value, and what is and is not a token.
